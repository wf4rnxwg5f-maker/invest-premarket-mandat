# Мандат ИИ-агента: проверяемые полномочия на брокерском счёте

Материалы к диагностическому заданию «Инвест. Премаркет»: три пилотных замера на реальных данных и прототип детерминированного шлюза. Ответы анкеты: [`answers_codenrock.md`](answers_codenrock.md) — отправленная сжатая версия, [`answers_final.md`](answers_final.md) — полная.

**Идея.** Клиент своими словами задаёт рамки для своего ИИ-агента («не больше 10% в одну компанию, третий эшелон не бери, ОФЗ не продавай»). LLM переводит текст в закрытый язык правил и уточняет расплывчатые понятия на реальных бумагах. Детерминированный шлюз перед T-Invest MCP проверяет каждую заявку агента: «пропустить», «спросить владельца» или «отклонить», с номером правила и записью в журнал. В контуре исполнения LLM нет.

## Пилот 1. У бытовых понятий нет одного прочтения

Данные MOEX ISS: режим TQBR (261 акция и расписка) и TQCB (корпоративные облигации), торговый день 12.11.2026, медианный оборот за 20 торговых дней (15.10–12.11.2026), составы индексов на 12.11.2026. Расчёт — [`pilot/scripts/readings.py`](pilot/scripts/readings.py), вывод — [`pilot/readings.txt`](pilot/readings.txt).

| Понятие из мандата | Прочтения | Где решения расходятся |
|---|---|---|
| «ВДО» | третий уровень листинга / доходность ≥ ключевая ставка (14%) + 5 п.п. | 441 из 1451 рублёвой корпоративной облигации с торгами (30%), Жаккар 0,51 |
| «Третий эшелон» | третий уровень листинга / вне индекса MOEXBMI / медианный оборот < 10 млн ₽ в день | 30 из 261 акции (11%), в том числе Магнит (19-я по обороту), Газпром нефть (капитализация 2,5 трлн ₽), СПБ Биржа, ДВМП |
| «Голубые фишки» | индекс MOEXBC / топ-15 по капитализации / топ-15 по обороту | совпадают 12, всего в объединении 20 бумаг |
| «Не больше 10% в Газпром» | акция / эмитент ПАО / с облигациями ООО «Газпром капитал» / группа | 1 акция → +2 облигации и 2 фьючерса ПАО → +57 облигаций «Газпром капитала» → +26 инструментов «Газпром нефти» (справочник эмитентов ISS на 13.11.2026); по названию цепляются ещё 59 облигаций Газпромбанка |

Вывод: смысл такого правила нельзя вшить в форму заранее. Его приходится выяснять у клиента, причём на тех бумагах, где прочтения расходятся. Это и есть работа для AI, а решение по заявке остаётся за кодом.

## Пилот 2. Сколько реальных правил инвесторов помещается в форму лимитов

Корпус: 51 публичный набор личных правил частных инвесторов, 342 атомарных правила (39 наборов на русском, 12 на английском). Baseline — сильная форма лимитов из 15 полей на справочнике брокера. Разметка: закрытая таксономия, два независимых прохода LLM-разметки (κ = 0,91), расхождения разобраны арбитражем. Выборочная сверка 20 источников с первоисточником нашла 151 цитату из 151.

| Показатель | Значение |
|---|---|
| Покрытие формой проверяемых ограничений | **23%** (95% ДИ 16–30%, бутстреп по авторам) |
| То же, щедрый пересчёт | 31% (24–40%) |
| Наборов хотя бы с одним ограничением вне формы | 43 из 48 (90%) |
| Ограничения на расплывчатых понятиях | 17% проверяемых |
| Формулировки, которые вовсе не ограничения (принципы и обязанности) | 46% |

Метод, таблицы и ограничения — в [`pilot/coverage/summary.md`](pilot/coverage/summary.md), расчёт — [`pilot/scripts/coverage_stats.py`](pilot/scripts/coverage_stats.py).

## Пилот 3. Сама AI-часть

Две LLM одного семейства (в MVP — разных) разобрали 16 реальных мандатов из корпуса пилота 2 (147 пунктов) в черновой закрытый язык правил ([`pilot/p3/dsl.md`](pilot/p3/dsl.md)).

- Молча не пропущен ни один пункт. Два лимита из 86 модели приняли за принцип; один из них поймала сверка двух моделей: одна сказала «принцип», другая — «уточнить».
- Ни одно из 17 расплывчатых понятий не истолковано молча: 13–15 помечены «нужно уточнить», остальные — «не могу выразить».
- Принципы и обязанности отделены от лимитов в 69–77% случаев; ошибки — в безопасную сторону (лишний вопрос, а не тихое разрешение).
- Язык v0 выразил 29–42% точных правил; недостающее (тип заявки, лимит в лотах, события эмитента) — бэклог языка.

LLM-судья без уточнения решал по 40 акциям при 5 почти равнозначных формулировках «третьего эшелона», по 2 прогона на формулировку. По 30 акциям, где прочтения расходятся, у 25 решения различались, а повтор той же формулировки менял решение в 31% случаев. Систематического эффекта формулировки нет: это случайность модели там, где смысл неоднозначен. По 10 бесспорным акциям — ни разу.

Подробности — [`pilot/p3/summary.md`](pilot/p3/summary.md).

## Почему не другие идеи

Мы сравнили 23 идеи ([`ideas.md`](ideas.md)) и отбросили те, где AI не нужен. Пример — «агент окна оферты»: дату окончания окна правило «последние 5 рабочих дней купонного периода» находит верно в 95–97% классических пут-оферт, окно целиком — в 87–88%. Подробности — [`pilot/offer_window/`](pilot/offer_window/).

## Прототип шлюза

[`prototype/mandate_engine.py`](prototype/mandate_engine.py) — чистая функция «политика × состояние × заявка → решение».

Принципы движка:
- белый список действий: всё, что мандат явно не разрешил, — «спросить владельца»;
- лимиты считаются по выставленным заявкам (исполненные + активные + новая), а не только по исполненным;
- рыночная заявка оценивается проходом по стакану на весь объём;
- нет данных — «спросить», ошибка в движке — «отклонить».

15 тестов в [`prototype/test_engine.py`](prototype/test_engine.py):
- сценарий из анкеты: из четырёх заявок три проходят, неликвидная отклоняется по правилу об обороте; продажа акций и покупка облигаций уходят владельцу на «спросить», продажа ОФЗ и фьючерсы отклоняются;
- одна и та же заявка решается по-разному при прочтении «уровень листинга» и «оборот», «на бумагу» и «на группу», с деньгами и без денег в знаменателе;
- дробление и пачки неисполненных заявок упираются в дневной лимит; резерв денег под активные заявки — в запрет плеча; активные продажи — в запрет шорта;
- 3 000 случайных последовательностей «выставить / частично исполнить / снять»: не нарушаются ни доля группы, ни дневные лимиты, ни запреты плеча, шорта и продажи ОФЗ.

```bash
cd prototype && python3 -m unittest test_engine -v
```

## Как воспроизвести

Сырые данные MOEX ISS по условиям биржи в репозиторий не выкладываются, их скачивают скрипты. Числа в README сняты 12–13.11.2026; повторный запуск возьмёт текущие данные.

```bash
python3 pilot/scripts/fetch_iss.py pilot/data 20        # снимки TQBR/TQCB, 20 дней истории, индексы, эмитенты
python3 pilot/scripts/readings.py pilot/data             # пилот 1
python3 pilot/scripts/coverage_stats.py pilot/coverage/raw_public.json pilot/coverage   # пилот 2
python3 pilot/scripts/pilot3_stats.py pilot/p3/raw_p3.json pilot                        # пилот 3
cd pilot/offer_window && python3 fetch_offers.py && python3 ruletest3.py               # окно оферты
```

Корпус пилота 2 опубликован без дословных цитат: в нём пересказы правил, ссылки на первоисточники и разметка.
